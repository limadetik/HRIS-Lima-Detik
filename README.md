# HRIS Lima Detik Group

Prototype HRIS dashboard for a small company with employee data, attendance, leave, and policy lookup.

## Run locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173/
```

## Features

- Login with employee / supervisor / HR role
- Employee directory
- Attendance overview
- Leave and approval status
- Policy / regulation listing
- "Tanya Peraturan Perusahaan" logic that matches employee questions to a related policy article

This is currently a front-end demo using sample data.
